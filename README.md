## 🚀 Огляд проєкту

Програма призначена для автоматизації процесу багатокритеріального аналізу та прийняття рішень за методом аналізу ієрархій Томаса Сааті (*Analytic Hierarchy Process, AHP*). Вона дозволяє декомпозувати складну проблему вибору на трирівневу ієрархію:

```
[Рівень 0: Фокус / Мета вибору]
          │
          ▼
[Рівень 1: Критерії оцінювання (C1, C2, ..., Cn)]
          │
          ▼
[Рівень 2: Доступні альтернативи (A1, A2, ..., Am)]
```

Користувач проводить попарні порівняння критеріїв та альтернатив за 9-бальною шкалою Сааті, після чого система автоматично розраховує локальні й глобальні пріоритети, верифікує узгодженість матриць ($CI, CR, CR_h$), формує рекомендацію для особи, що приймає рішення (ОПР), та надає інтерактивний аналіз чутливості рейтингу.

## 📐 Математичний апарат системи

### 1. Розрахунок локальних пріоритетів (вектора ваг $w$)
Підтримується три методи:
- **Нормалізація стовпців (Column Normalization / методичний підхід)**:
  $$S_j = \sum_{i=1}^n a_{ij}, \quad N_{ij} = \frac{a_{ij}}{S_j}, \quad w_i = \frac{1}{n} \sum_{j=1}^n N_{ij}$$
- **Середнє геометричне (Geometric Mean / LLSM)**:
  $$g_i = \sqrt[n]{\prod_{j=1}^n a_{ij}}, \quad w_i = \frac{g_i}{\sum_{k=1}^n g_k}$$
- **Степеневий метод Сааті (Principal Eigenvector / Power Iteration)**:
  Ітераційний пошук власного вектора:
  $$w^{(k+1)} = \frac{A \cdot w^{(k)}}{\|A \cdot w^{(k)}\|_1}, \quad \text{досягнення точності } \|w^{(k+1)} - w^{(k)}\|_\infty < 10^{-7}$$

### 2. Максимальне власне число $\lambda_{\max}$
- **Добуток сум стовпців на ваги (за методичними рекомендаціями)**:
  $$\lambda_{\max} = \sum_{j=1}^n S_j \cdot w_j$$
- **Середнє відношення рядків (Row Ratio Mean)**:
  $$\lambda_{\max} = \frac{1}{n} \sum_{i=1}^n \frac{(A \cdot w)_i}{w_i}$$
- **Точне власне число (Power Iteration)**:
  Обчислюється безпосередньо зі степеневої збіжності:
  $$\lambda_{\max} = \|A \cdot w\|_1$$

### 3. Індекс та коефіцієнт узгодженості
- **Індекс узгодженості ($CI$)**:
  $$CI = \frac{\lambda_{\max} - n}{n - 1}$$
- **Випадковий індекс ($RI$)**:
  - Таблиця Т. Сааті ($n \le 10$): $n=3 \to 0.58$, $n=4 \to 0.90$, $n=5 \to 1.12$, $n=6 \to 1.24$, $n=7 \to 1.32$, $n=8 \to 1.41$, $n=9 \to 1.45$, $n=10 \to 1.49$.
  - Емпірична формула: $RI = 1.98 \cdot \frac{n - 2}{n}$.
- **Коефіцієнт узгодженості ($CR$)**:
  $$CR = \frac{CI}{RI}$$
- **Умова узгодженості**: $CR \le 0.10$ (або адаптивно за Сааті: $n=3 \to 0.05$, $n=4 \to 0.08$, $n \ge 5 \to 0.10$).

### 4. Ієрархічний синтез та композиційна узгодженість ($CR_h$)
- **Глобальний пріоритет $i$-ї альтернативи**:
  $$P_i = \sum_{j=1}^n L_{ij} \cdot w_j$$
- **Композиційний індекс і коефіцієнт**:
  $$CI_h = CI_{crit} + \sum_{j=1}^n w_j \cdot CI_{alt, j}, \quad RI_h = RI_{crit} + \sum_{j=1}^n w_j \cdot RI_{alt, j}, \quad CR_h = \frac{CI_h}{RI_h} \le 0.10$$
  *Примітка: для композиційної узгодженості ієрархії $CR_h$ завжди застосовується фіксований нормативний поріг $10\%$, незалежно від режиму окремих матриць.*

## 🎯 Профілі розрахунку (Calculation Profiles)

Система надає можливість вибору між двома стандартизованими профілями розрахунку:
1. **Профіль «За методичними рекомендаціями»**:
   - Метод розрахунку ваг: нормалізація стовпців.
   - Метод $\lambda_{\max}$: сума добутків стовпців на ваги ($\sum S_j \cdot w_j$).
   - Розрахунок $RI$: емпірична формула $1.98 \cdot (n-2) / n$.
   - Поріг узгодженості: фіксований $10\%$ для всіх розмірностей.
2. **Профіль «Класичний метод Т. Сааті»**:
   - Метод розрахунку ваг: головний власний вектор (степеневий метод).
   - Метод $\lambda_{\max}$: точне головне власне число ($\|A \cdot w\|_1$).
   - Розрахунок $RI$: класична емпірична таблиця Сааті.
   - Поріг узгодженості: адаптивний Сааті ($5\%$ для $n=3$, $8\%$ для $n=4$, $10\%$ для $n \ge 5$).

## 💡 Підказки при неузгодженості

Якщо коефіцієнт узгодженості матриці перевищує допустимий поріг ($CR > CR_{\max}$), система надає інтелектуальну підказку для покращення узгодженості:
1. Знаходить елемент $(i, j)$ у верхньому трикутнику з найбільшим абсолютним відхиленням від ідеального відношення ваг:
   $$\max_{i < j} \left| a_{ij} - \frac{w_i}{w_j} \right|$$
2. Розраховує теоретичне узгоджене значення $Implied = w_i / w_j$.
3. Знаходить рекомендоване значення $s$ на фундаментальній 9-бальній шкалі Сааті ($1/9 \dots 9$), що мінімізує логарифмічне відхилення:
   $$\min_{s \in \text{Saaty}} |\ln(Implied) - \ln(s)|$$
4. У картці діагностики виводиться текст: *«Найбільш неузгоджена пара: C1 vs C4 (поточне: 2.0, узгоджене: ≈3.86, рекомендується: 4)»*.
5. Відповідна комірка у таблиці попарних порівнянь підсвічується акцентною рамкою для швидкого знаходження користувачем.

## 📈 Аналіз чутливості (Sensitivity Analysis)

При зміні ваги обраного критерію $k$ на значення $t \in [0, 1]$ ваги решти критеріїв пропорційно масштабуються:
$$w_j(t) = w_j^0 \cdot \frac{1 - t}{1 - w_k^0}, \quad j \ne k$$

Глобальний пріоритет кожної $i$-ї альтернативи є лінійною функцією параметра $t$:
$$P_i(t) = \alpha_i \cdot t + \beta_i$$

Точки зміни лідера визначаються як точні точки перетину двох провідних альтернатив:
$$t^* = \frac{\beta_m - \beta_i}{\alpha_i - \alpha_m} \in (0, 1)$$

Програма автоматично будує графік функцій $P_i(t)$, знаходить дійсні точки зміни лідера (ігноруючи перетини аутсайдерів) та розраховує інтервал стійкості $[t_{\min}, t_{\max}]$ поточного переможця із запасом стійкості у відсоткових пунктах.

## 🛠 Інструкція зі збирання та запуску

### Вимоги до системи:
- Операційна система: **Windows 10 / 11 (x64)**
- Для запуску готового портативного білду: додаткове встановлення .NET **не потрібне**.
- Для збирання з вихідного коду: встановлений **.NET 10 SDK** (або новіший).

---

### Запуск та налагодження з вихідного коду:

1. Клонуйте репозиторій та перейдіть у каталог проєкту:
   ```powershell
   git clone <URL_РЕПОЗИТОРІЮ>
   cd SysAnalysis/MAI
   ```

2. Зберіть проєкт:
   ```powershell
   dotnet build MAI.csproj -c Debug
   ```

3. Запустіть програму:
   ```powershell
   dotnet run --project MAI.csproj
   ```

---

### Створення автономного портативного білду (Single-File):

Програма підтримує повну автономну публікацію в один виконуваний файл (`MAI.exe`), який містить усі бібліотеки, WPF-середовище та рантайм .NET 10:

```powershell
dotnet publish MAI.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true `
  -o ./publish
```

Скомпільований файл розміщується у папці `./publish/MAI.exe` і запускається на будь-якому комп'ютері з Windows x64 у «portable» режимі без встановлення .NET.

## 📦 Автоматизація релізів (GitHub Actions CI/CD)

У репозиторії налаштовано пайплайни GitHub Actions:
1. **`.github/workflows/ci.yml`**: запускається при push та pull request у гілки `main` та `develop`, компілює рішення та проганяє повний набір модульних тестів.
2. **`.github/workflows/release.yml`**: запускається при створенні тегу версії (`v*`) або вручну, виконує тести, компілює портативний `win-x64` Single-File білд, архівує його у `zip` та автоматично формує новий **GitHub Release**.
