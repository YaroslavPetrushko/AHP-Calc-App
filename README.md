## 🚀 Огляд проєкту

Програма автоматизує процес прийняття рішень за методом аналізу ієрархій Томаса Сааті (*Analytic Hierarchy Process*). Вона дозволяє розкласти складну задачу вибору на трирівневу ієрархічну модель:

```
[Рівень 0: Фокус / Мета вибору]
          │
          ▼
[Рівень 1: Критерії оцінювання (P, F, A, C)]
          │
          ▼
[Рівень 2: Доступні альтернативи (A1, A2, ..., Am)]
```

Дизайн інтерфейсу уніфіковано з попередніми лабораторними роботами (сучасна палітра Slate/Blue, картки з плавними тінями, кольорові бейджі оцінок та інтуїтивне керування).

## ✨ Основні можливості

1. **Динамічне формування моделі**:
   - Налаштування довільної кількості критеріїв та альтернатив (від 2 до 8).
   - Редагування назв та детальних описів об'єктів.
2. **Інтерактивні матриці попарних порівнянь**:
   - Підтримка фундаментальної 9-бальної шкали Сааті: цілі числа (`1..9`), дроби (`1/2..1/9`) та десяткові дроби (`0.5`, `0.333`).
   - Автоматичне заповнення симетричних клітинок оберненими значеннями ($a_{ji} = 1 / a_{ij}$).
   - Діагональ матриць автоматично заблокована на значенні `1.0`.
3. **Контроль узгодженості суджень (Consistency Check)**:
   - Миттєвий підрахунок максимального власного числа $\lambda_{max}$, індексу узгодженості $CI$ та коефіцієнта $CR$.
   - Підтримка як класичної таблиці випадкових індексів Сааті ($RI_{табл}$), так і емпіричної формули $RI = 1.98 \cdot (n - 2) / n$.
   - Кольорова візуалізація статусу: зелений (при $CR \le 0.10$ — узгоджено), червоний (при порушенні транзитивності суджень).
4. **Дводіапазонне вікно результатів (`ResultsWindow`)**:
   - **📊 Компактний підсумок**:
     - Турнірна таблиця рейтингу альтернатив із рангами (#1..#m) та візуальними графічними прогрес-барами.
     - Бейдж переможця вибору 🏆.
     - Розподіл ваг критеріїв у вигляді карток.
     - Автоматично згенерований аналітичний висновок та рекомендація для ОПР.
   - **🔬 Детальний математичний аналіз**:
     - Зведена матриця ієрархічного синтезу з розкладанням локальних оцінок ($L_{ij}$) та зваженого внеску кожного критерію ($L_{ij} \cdot w_j$).
     - Зведена таблиця перевірки узгодженості для всіх матриць системи та загального показника ієрархії $CR_h$.
     - Інспектор нормалізованих матриць та векторів пріоритетів.
     - Експорт результатів: копіювання повного текстового звіту в буфер обміну або збереження у файл `.txt`.
5. **Вбудовані тестові пресети**:
   - Пресет «Лабораторні роботи №3–4» (4 критерії, 5 альтернатив відеокарт).
   - Пресет «Курсова робота» (актуалізований модельний ряд відеокарт 2026 року).
   - «Нова задача» (чистий шаблон для користувацьких даних).

## 📐 Математичний апарат МАІ

### 1. Нормалізація та вектор ваг
Для кожної зворотно-симетричної матриці розміром $n \times n$:
- Обчислюються суми стовпців:
  $$S_j = \sum_{i=1}^n a_{ij}$$
- Елементи нормалізуються діленням на суму стовпця:
  $$N_{ij} = \frac{a_{ij}}{S_j}$$
- Вектор локальних пріоритетів (ваг) формується як середнє нормалізованого рядка:
  $$w_i = \frac{1}{n} \sum_{j=1}^n N_{ij}$$

### 2. Максимальне власне число $\lambda_{max}$ та індекс узгодженості $CI$
- Множенням вихідної матриці на вектор ваг визначається вектор сумісності $v = A \cdot w$.
- Розраховується власне значення:
  $$\lambda_i = \frac{v_i}{w_i}, \quad \lambda_{max} = \frac{1}{n} \sum_{i=1}^n \lambda_i$$
- Індекс узгодженості:
  $$CI = \frac{\lambda_{max} - n}{n - 1}$$

### 3. Коефіцієнт узгодженості $CR$
$$CR = \frac{CI}{RI}$$
- $RI_{табл}$: $n=3 \to 0.58$, $n=4 \to 0.90$, $n=5 \to 1.12$, $n=6 \to 1.24$.
- $RI_{емп} = 1.98 \cdot \frac{n - 2}{n}$ ($n=4 \to 0.99$, $n=5 \to 1.188$).
- Умова прийнятності: $CR \le 0.10$ (10%).

### 4. Ієрархічний синтез
Глобальний пріоритет кожної $i$-ї альтернативи визначається лінійною згорткою:
$$P_i = \sum_{j=1}^k L_{ij} \cdot w_j$$
де $L_{ij}$ — локальний пріоритет $i$-ї альтернативи за $j$-м критерієм, $w_j$ — вага $j$-го критерію.

### 5. Композиційна узгодженість ієрархії ($CR_h$)
$$CI_h = CI_{crit} + \sum_{j=1}^k w_j \cdot CI_{alt, j}, \quad RI_h = RI_{crit} + \sum_{j=1}^k w_j \cdot RI_{alt, j}$$
$$CR_h = \frac{CI_h}{RI_h} \le 0.10$$

### Набір 1: Лабораторні роботи №3–4 (Вибір відеокарти для студента CS)
- **Критерії**:
  - `P` — Productivity (Продуктивність): чистий FPS у растровому рендерингу.
  - `F` — Functionality (Функціональність): обсяг VRAM, екосистема CUDA, тензорні ядра під AI/ML.
  - `A` — Actuality (Актуальність): DLSS/FSR, апаратні кодеки AV1, енергоефективність.
  - `C` — Cost (Вартість): цінова доступність за даними роздробу України.

## 🛠 Інструкція зі збирання та запуску

### Вимоги:
- Операційна система: **Windows 10 / 11**
- Встановлений **.NET 10 SDK** (версія 10.0 або вище)

### Команди:
Збірка проєкту в Debug-конфігурації:
```powershell
dotnet build MAI.csproj -c Debug
```

Запуск застосунку:
```powershell
dotnet run --project MAI.csproj
```

Виконуваний файл буде розташовано за адресою:
`*repo*\bin\Debug\net10.0-windows\MAI.exe`
